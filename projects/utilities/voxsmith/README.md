# voxsmith

Operations over `voxcore` states. `operations` holds one module and feature per `vxl` command group. `utilities` holds palette reduction, dithering, color spaces, the material property ranges, the object and node selectors, and the voxelizers' grid resolution and frame. `dependencies` holds the traits the operations take from the caller: the PNG encoder the mesh bake and the render write through, and the voxelizer's image decoder. `DependenciesImpl`, behind the `impl` feature, binds them over `png` and `zune-jpeg`. The voxel file formats live in `voxconv`, the mesh file formats in `meshconv`, and the SDF file formats in `sdfconv`. The mesher and the corner occlusion live in `voxsurface`.
